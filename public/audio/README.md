# Background Music

Đặt file `bg-music.mp3` vào thư mục này để nút music nền trên Header hoạt động.

- Tên file yêu cầu: `bg-music.mp3`
- Format: MP3, nên dưới 3MB để tải nhanh
- Gợi ý: nhạc lofi/gaming không bản quyền (Pixabay, Bensound, NCS)
- Nhạc sẽ loop, volume mặc định 30%, không tự phát (browser chặn), người dùng phải click nút music để bật

File không được commit lên git (xem `.gitignore` nếu cần).
